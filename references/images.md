# 图片策略

苹果页面高度依赖图片质量，但**无图也必须成立**（纯排版是必选基线）。三种来源按决策树选定：

```
用户提供了图片？
├─ 是 → 走「用户图片」规范（下 §二）
└─ 否 → 环境里有可用的文生图能力，且用户接受 AI 配图？
    ├─ 是 → 走「AI 配图」规范（下 §三）
    └─ 否 → 纯排版（下 §四）
```

---

## 一、通用规则（三种来源都遵守）

1. **背景融合是生死线**：light 模式图片底色必须接近 `#FBFBFD`；dark 模式必须接近纯黑 `#000000`。底色不融合的产品图 = 一张贴纸钉在页面上，立刻廉价。渲染预览时逐张检查图片四角与页面背景是否有色差断层。
2. product-hero 用 `contain`（产品漂浮）；split 用 `cover`（半屏满铺，裁剪保比例）。禁止拉伸变形。
3. 一页最多一张图。图片上**永远不压文字**（split 的文字在另一半区）。
4. 同一场 PPT 里所有图片的摄影风格必须一致（同为影棚棚拍 / 同为实景），混搭即违和。

## 二、用户图片

1. 先用脚本或预览确认图片尺寸与主色调，再决定给哪个版式：
   - 横图/大图 → split（cover 满铺半屏）或 product-hero
   - 方图/白底产品图 → product-hero（contain）
   - 多张同系列小图 → gallery
2. 分辨率下限：最终显示区域像素密度 ≥96 DPI，即 cover 半屏（6.4×7.5in）至少 615×720px，全屏 hero 至少 1280×720。过小的图宁可不用。
3. 底色不融合时，不要用半透明遮罩硬压（那是杂志风不是苹果风），改选深色/剪影感更强的图，或该页回落纯排版。

## 三、AI 配图

生成前确认宿主环境可用的文生图工具（如即梦/Seedance 文生图、DALL·E 等）。逐页生成，先出**主图**（product-hero 用），其余页复用其风格。

提示词模板（按模式二选一，`{主体}` 替换为产品名）：

```
【light 模式】
商业产品摄影，{主体} 居中悬浮在纯白背景前，背景色 #FBFBFD，柔和均匀的
顶侧光，底部轻微柔和倒影，极简，高端质感，画面无任何文字和水印，16:9

【dark 模式】
商业产品摄影，{主体} 居中悬浮在纯黑背景前，背景色 #000000，轮廓光勾勒
边缘，微弱顶光保留材质细节，深色影棚氛围，极简，高端质感，画面无任何
文字和水印，16:9
```

负面要求（写进提示词或作为排除项）：文字、水印、logo、边框、杂乱背景、多主体、强透视。

生成后逐张检查：四角底色是否融合（§一.1）、主体居中完整、无伪文字乱码、风格与主图一致。不合格重生成**一次**，仍不合格回落纯排版——不进入无限重生成循环。

版权与署名：AI 配图在交付说明中注明"配图由 AI 生成"。

## 四、纯排版回落（必选基线）

没有图片时，用排版本身撑起苹果感：

1. `product-hero` 无图 → title 升级 hero 字号居中（版式库已内置回落）。
2. `split` 无图 → 拆成一页 statement + 一页 bignum/feature-grid，或改 feature-grid。
3. `gallery` 无图且 item 有 `color` → 色块阵列（色板本身就是内容）。
4. 增加重音页频率：无图版把三页一高潮收紧为两页一重音（statement/bignum 交替）。
5. 允许用 8% tint 的纯色大色块做视觉锚（dark 模式 `#1D1D1F` 面板），但单页最多一块。

自检：把无图版逐页渲染后眯眼看——如果某页"全是小字"，说明密度超标，回炉拆页。
