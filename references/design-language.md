# 苹果发布会视觉设计语言

本文件是 `apple-keynote-ppt` 的完整视觉规范。`scripts/apple_theme.js` 已把这些规范固化为常量和版式函数——日常生成不需要手写这些数值；只有当用户明确要求偏离、或需要新增版式时才需要读本文件并改主题库。

与 `seedance-apple-keynote-video`（视频版）共享同一套色彩基因，保证用户先做视频再做 PPT 时风格统一。

## 一、双模式色板

苹果有两条并行的视觉世界：**官网浅色**（#FBFBFD 纯白影棚）与**发布会深色**（纯黑舞台）。一场 PPT 只选一种模式，绝不混用。

| 角色 | 浅色模式 light | 深色模式 dark |
|---|---|---|
| 背景 BG | `#FBFBFD` | `#000000` |
| 主文字 TEXT | `#1D1D1F` | `#F5F5F7` |
| 次要文字 MUTED | `#86868B` | `#86868B`（两种模式相同） |
| 面板/色块底 | `#FFFFFF` 或主色 8% tint | `#1D1D1F` 或主色 15% tint |
| 分隔线 | `#D2D2D7` | `#424245` |

**模式选择**：发布会/新品/科技感/戏剧化 → dark；工作汇报/商务介绍/阅读型文档 → light。用户没说时默认 dark（"发布会风"的直接联想）。

强调色：只在深色模式允许"克制的系统蓝" `#0A84FF`、浅色模式 `#0071E3`（Apple 官网按钮蓝），用于个别关键词或链接，占比 ≤10%。

## 二、渐变标题色带

叙事性大字（hero 标题、大数字、结尾 slogan）可用苹果标志性的四色渐变：

```
#8B5CF6（紫） → #4F8DEB（蓝） → #46C7C7（青） → #58C878（绿）
```

使用规则：

1. **一场 PPT 最多 3–4 页用渐变**：封面标题、1–2 个大数字页、结尾 slogan。全篇渐变 = 廉价。
2. 渐变只用于**短大字**（≤12 字）。正文、章节标题、功能点标题永远纯色。
3. 渐变方向一律从左到右（水平）。pptxgenjs 不支持渐变文字，主题库通过"渐变标记 + XML 后处理"实现（见下）。
4. 不确定是否该用渐变时：dark 模式 + 戏仿/发布会语境 → 用；light 模式 + 汇报语境 → 不用。

**技术实现**（`apple_theme.js` 已封装，此处仅说明原理）：给需要渐变的文本框设置 `objectName: "grad:xxx"`，pptxgenjs 生成后由 `scripts/postprocess_gradient.py` 把这些文本框内的 `<a:solidFill>` 替换为四色 `<a:gradFill>`。postprocess 由 `build_deck.js` 自动调用，无需手动执行。

## 三、字体

| 场景 | 字体 | 字重 |
|---|---|---|
| 中文标题/大字 | 微软雅黑 Microsoft YaHei | Bold |
| 中文正文 | 微软雅黑 Microsoft YaHei | Regular |
| 西文标题/大字 | Segoe UI（最接近 SF Pro 的 Windows 自带字体） | Bold / Semibold |
| 西文正文 | Segoe UI | Regular |
| macOS 打开 | 自动回落苹方 PingFang SC / SF Pro，无需处理 | — |

规则：

1. 每个文本 run 显式设置 `fontFace`，绝不依赖主题继承（主题库的 `pickFont()` 自动按文本含不含 CJK 选择雅黑或 Segoe UI）。
2. **中文不用 Light/Thin 字重**。视频里 PingFang Light 的纤细感是渲染成像素后固定的；PPT 要在别人机器上打开，Light 字重渲染不可控。纤细感改由"大字号 + 加大字距 + 降低对比"实现。
3. 一场 PPT 最多两个字体家族（雅黑 + Segoe UI 算一套中西文搭配）。
4. 大字字距略微放宽：hero/eyebrow 加 `charSpacing`（eyebrow 3pt、hero 1pt），这是苹果"呼吸感"的关键细节。
5. 禁止楷体、行楷、隶书、艺术字；中文文本框宽度比 Latin 直觉多留 15%。

## 四、字号阶梯

画布 13.33 × 7.5 英寸（LAYOUT_WIDE）下的绝对字号：

| 层级 | 字号 | 用途 |
|---|---|---|
| Hero 宣言 | 60–96pt | 封面标题、整页宣言、结尾 slogan |
| 大数字 | 100–160pt | 参数页的数字/倍数/价格 |
| 章节标题 | 44–54pt | 章节页、宣言页 |
| 页面标题 | 30–40pt | 内容页顶部结论句 |
| 小标题 | 20–24pt | 功能点标题、对比栏标题 |
| 正文 | 16–20pt | 功能点描述、对比明细 |
| Eyebrow/kicker | 14–18pt | 标题上方的小型大写引导词 |
| 注释/来源 | 12–14pt | 脚注、免责声明，最低 12pt |

原则：**苹果的大字号是内容分层，不是装饰**。一页里最多两个字号层级跳跃（如 120pt 数字 + 18pt 注释），层级过多说明这一页信息过载，应该拆页。

## 五、留白与对齐

1. 页边距 ≥1.0 英寸；内容占画布 ≤70%，**留白 ≥40%**。
2. **一页一个观点**。写完大纲后逐页自问"这页删掉一半字还成立吗"，成立就删。
3. 标题即结论："快了 2 倍"、"一杯，六种茶"。禁止"性能提升"、"产品介绍"这类无观点标题。
4. 居中用于宣言类页面（封面/宣言/大数字/定价/结尾）；左对齐用于阅读类页面（章节/功能/对比）。
5. 元素间距用 8pt 网格的倍数（0.11in 的整数倍），同组元素间距一致。

## 六、禁止清单（AI 味消除）

苹果感 = 克制。以下全部禁止：

- ❌ 标题下划线、彩色边条、侧边色条、页眉横线
- ❌ 图标堆砌（每个功能点配一个 emoji/图标 = 重灾区）
- ❌ 居中大段正文（正文要么左对齐，要么改成大字宣言）
- ❌ 2×2/3×3 卡片网格（带边框圆角底色的卡片每 5 页最多 1 页）
- ❌ 描边文字、文字阴影、发光效果
- ❌ 装饰性小字、乱码占位符、意义重复的英文标语
- ❌ 超过一种特殊效果（渐变 + 阴影 + 图标同时出现 = 灾难）
- ❌ 8 位 hex 颜色值（pptxgenjs 会损坏文件；主题库的 `cleanHex()` 已自动去除 `#` 和透明段）

## 七、图片与配色氛围

- 图片是苹果页面的主角之一：产品图"漂浮"在背景上，不装框、不加边。
- 浅色模式配白底产品图（#FBFBFD 底色可无缝融合）；深色模式配黑底产品图或剪影感图片。
- 图片处理一律 `cover`（半屏满铺）或 `contain`（产品漂浮），禁止拉伸变形。
- 详细规范见 `images.md`。
