# 叙事结构模板

苹果发布会的本质是**单线叙事 + 节奏控制**：一个主角、一条悬念、每页只推进一步。大纲阶段先在这里选结构，再填 outline.json。

## 一、三种通用结构

### 短版（6–8 页）：快速介绍 / 提案开场

```
cover → statement（一句话定位）→ bignum（核心数据 ×1–2）→ product-hero 或 split ×2 → closing
```

### 标准版（10–14 页）：产品介绍 / 汇报主干 ★ 默认

```
cover                    封面：产品/主题名 + 日期
statement                一句话定位（"这一次，我们重新定义了 X"）
section 01               章节一：设计/现状
  product-hero 或 split    主视觉 + 观点
  bignum                  本章节最硬核的一个数字
section 02               章节二：能力/方案
  split ×2                两个功能，一图一言
  feature-grid            剩余卖点收拢成 3 点
compare                  新旧对比 / 与传统方案对比
quote                    一句背书（可选）
pricing / bignum         关键结论：价格、收益或目标
closing                  slogan + 行动号召
```

### 深度版（15–20 页）：发布会全流程 / 年度汇报

标准版基础上增加：每个章节 2–3 页（章节页 + 主图页 + 大数字页）、gallery（系列/多方案阵列）、第二组 compare。**超过 20 页必须拆成两场**。

## 二、节奏规则

1. **三页一高潮**：每 3–4 页安排一个"重音"页（statement / bignum / quote），纯信息页连续不超过 3 页。
2. **开场 90 秒定调**：前 3 页必须出现一个可被转述的句子和一个可被记住的数字。
3. **信息密度递减**：中场可以密（split、feature-grid），结尾必须疏（pricing、closing 一页一句话）。
4. 大数字页是苹果的灵魂：**任何卖点先问"能量化吗"，能就给 bignum 一页**。

## 三、戏仿发布会模板（对齐 seedance-apple-keynote-video）

把任意普通产品包装成苹果新品时的专用叙事，文案结构与视频 skill 的 15 步发布顺序一一对应：

| 步 | 文案要点 | 推荐版式 |
|---|---|---|
| 1 | Apple + 英文产品名（命名宣言） | cover |
| 2–3 | "这一次，我们重新定义了" | statement |
| 4 | 中文产品名称 | statement 或 cover 副标题 |
| 5 | "X 款全新配色" | section |
| 6 | 各款产品名称（色板阵列） | gallery |
| 7 | 一条结构卖点 | split |
| 8 | 一条交互/配件卖点 | split |
| 9 | 一条内部性能卖点（虚构芯片） | bignum |
| 10 | 一条使用收益 | bignum 或 feature-grid |
| 11 | 手机连接类荒诞功能 | split |
| 12 | 两项可调参数及数值 | feature-grid |
| 13 | "小孩子才做选择" | quote |
| 14 | "成年人" | statement |
| 15 | "全部都要 / 全部加料 / 一次拥有" | pricing 或 closing |

示例文案链（奶茶）：

> Apple Milk Tea → 这一次，我们 → 重新定义了 → 苹果奶茶 → 六款全新配色 → （gallery：云朵乌龙/莓果气泡/…）→ 一体成型杯身（split）→ MagSafe 吸管（split）→ A1 爆珠核心（bignum：3nm 制香程）→ 冷热同杯（feature-grid）→ 蓝牙 5.3 连接手机（split）→ 甜度 0–100%、冰量 0–100%（feature-grid）→ 小孩子才做选择（quote）→ 成年人（statement）→ 全部都要（pricing）

**戏仿红线**（与视频 skill 相同）：画面严肃、精致、昂贵，笑点全部来自"把普通商品当尖端硬件发布"的反差；必须戏仿声明（pricing 或 closing 页的 note 一句"本作品为风格化戏仿，与 Apple Inc. 无关"）；不得声称苹果真实生产。

## 四、文案写作规则

1. 每页标题 = 一个可被转述的结论句。写完读一遍：观众散场后能复述这句话吗？
2. 数字优先于形容词："快 2 倍" > "极速"；"40 分钟续航" > "超长续航"。
3. 中文文案长度：hero ≤12 字、页面标题 ≤16 字、正文每条 ≤40 字。
4. 全篇统一一份文案表：PPT、讲稿、备注引用完全相同的文字，禁止多版本。
5. 克制幽默只出现在戏仿语境；商务汇报语境零段子。
